# Kahoot draft — eight questions, gimme → spicy

Every answer was on a slide; the quiz doubles as a recap. Kahoot limits:
question ≤ 120 chars, answers ≤ 75 chars. All fit. Correct answer marked ✔.

---

**1. What does a language model actually compute at each step?** *(gimme — Act 1)*
- A sentence at a time
- The next word it "wants" to say
- ✔ A probability for every token in its vocabulary
- A database lookup of similar text

**2. Why does counting the r's in "strawberry" break a plain LLM?** *(Act 2)*
- Not enough math in training data
- ✔ It sees tokens (chunks), not letters
- The context window is too short
- Floating-point rounding errors

**3. Turning the temperature UP makes a model…** *(Act 1)*
- Think longer before answering
- ✔ More willing to pick unlikely tokens
- Use more of its parameters
- Slower but more accurate

**4. One token from a 405B-parameter model costs about as much arithmetic as…** *(Act 3)*
- A day of a pocket calculator
- One Google search
- ✔ 84 minutes of 1976's fastest supercomputer
- Rendering one frame of a Pixar movie

**5. With a reasoning model, the extra money buys…** *(Act 4)*
- A bigger neural network
- ✔ Scratch-work tokens before the answer
- Access to the internet
- A second model checking the first

**6. Out of the box, GitHub Copilot is…** *(The Turn)*
- A sports car
- A truck
- ✔ A rental car
- A tank

**7. Which file teaches Copilot your repo's conventions?** *(Act 6)*
- README.md
- CONTRIBUTING.md
- ✔ .github/copilot-instructions.md
- .vscode/settings.json

**8. As engines get better, the harness should…** *(spicy — the thesis)*
- Get thicker — more rules, more examples
- Stay exactly the same
- Disappear entirely
- ✔ Shed compensation, grow capability
