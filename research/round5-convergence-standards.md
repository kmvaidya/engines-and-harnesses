# Convergence and standards across coding harnesses (round 5, 2026-11-04)

## Short version

- **The open standards now have one owner.** The Linux Foundation's Agentic
  AI Foundation (AAIF, launched Dec 9, 2025 with MCP, AGENTS.md and goose)
  added A2A on Aug 27, 2026 and Agent Skills on Oct 22, 2026. It hosts 10
  projects. ACP is the one widely used harness protocol outside it (Zed and
  JetBrains, Apache 2.0). [P]
- **Adoption, as counted by the stewards:** AGENTS.md "used by over 60k
  open-source projects" and 23 named tools; Agent Skills on "more than 70"
  platforms with "1 million skills" published; ACP registry lists 45 agents,
  and the ACP site lists about 50 agents and well over 60 clients. These are
  self-reported. [P]
- **Edit formats split by model vendor, not by harness.** Every multi-model
  harness we read (Copilot, Cline, OpenCode) gives GPT-family models
  `apply_patch` and everyone else an exact string-replace tool. Codex uses a
  freeform `apply_patch` grammar for every model in its catalog. Whole-file
  rewrites and fast-apply models have dropped out of the open harnesses. [P]
- **Edit-format evidence is thin but consistent on one point:** the format
  can matter more than the model for weaker models (hashline blog: Grok Code
  Fast 1 from 6.7% to 68.3%), and for strong models search/replace and
  str_replace do about as well as anything (Diff-XYZ v2). [P]
- **Code search: grep won in 2026.** Cursor, the loudest embeddings advocate
  in 2025 (12.5% accuracy gain, Nov 2025), turned semantic indexing off in
  July 2026 for "Instant Grep" and its docs now say it "does not store
  embeddings of your codebase for search". A source study of 11 harnesses
  found that "No system uses vector-embedding RAG for code retrieval". GitHub
  Copilot is the exception: it keeps and expands embedding search. [P]
- **System prompts got shorter while requests got longer.** Claude Code's
  system prompt was 9,517 characters in Aug 2026, but its first request was
  74,078 characters, 77% of it tool definitions. Codex's first request grew
  7.8x between Apr 2025 and Aug 2026. OpenCode's base prompt is 111 words;
  Codex's GPT-6.x prompts run 2,790 to 3,366 words (~~about 3,300 words~~
  held only for gpt-6-astra, 6.1-terra and 6.1-sol; corrected in the
  verification pass). [P]
- **The common core is one loop.** "An LLM agent runs tools in a loop to
  achieve a goal" (Willison, Sep 2025). Every harness ends a turn either when
  the model replies without a tool call or when it calls an explicit
  completion tool. Most of the code lives elsewhere: safety, UI, extension
  points and clients. [P]
- **Academic consensus (2026 source studies):** designs converge where
  outside constraints dominate (tool categories, edit formats, isolation) and
  diverge on context compaction, state and model routing (Rombaut, Apr 2026).
  "Skills have overtaken MCP" in adoption, 9 of 11 vs 8 of 11 (Barbaste et
  al., Jul 2026). Convergence has turned into copying: Codex adopted Claude
  Code's hook names, OpenHands its plugin manifest. [P]
- **AGENTS.md is a standard file, not a proven win.** A Feb 2026 ETH study
  (revised Sep 29, 2026) found that "providing context files does not
  generally improve task success rates" (~~"do not generally improve"~~,
  the abstract says "does not") and raises cost by over 20% on average; a smaller Jan 2026 study found
  28.64% lower median runtime. Both are true for different setups. [P]
- **[O] For a Copilot-only bank:** every standard here works in Copilot
  (AGENTS.md, CLAUDE.md, SKILL.md, Claude-format hooks, MCP, ACP via the
  CLI). Write team assets in the standard formats and they move with you if
  the approved tool list changes.

### 1.2 AGENTS.md

- [P] https://agents.md/: "A simple, open format for guiding coding
  agents." "AGENTS.md is now stewarded by the Agentic AI Foundation under
  the Linux Foundation." "used by over 60k open-source projects." No
  required fields; plain Markdown.
- [P] Precedence rule on the same page: "The closest AGENTS.md to the edited
  file wins; explicit user chat prompts override everything." The main
  OpenAI repo had 88 AGENTS.md files "at time of writing" (undated).
- [P] The 23 tools named on agents.md: Codex, Jules, Factory, Aider, goose,
  opencode, Zed, Warp, VS Code, Devin, UiPath Autopilot & Coded Agents,
  Junie, Amp, Cursor, RooCode, Gemini CLI, Kilo Code, Phoenix, Semgrep,
  GitHub Copilot coding agent, Ona, Windsurf, Augment Code. Claude Code is
  not on the list, though it reads AGENTS.md since v2.1.277 (2026-09-18)
  per `round5-claude-code.md`.
- [P] Codex is the reference implementation: global
  `~/.codex/AGENTS.md` or `AGENTS.override.md`, then one file per directory
  from the repo root down to the working directory, concatenated root
  first, capped at `project_doc_max_bytes` (32 KiB by default).
  https://learn.chatgpt.com/docs/agent-configuration/agents-md.md
- [P] Cursor: "Cursor supports AGENTS.md in the project root and
  subdirectories." Its own rules stay in `.cursor/rules/*.mdc` with four
  activation types (Always Apply, Apply Intelligently, Apply to Specific
  Files, Apply Manually). https://cursor.com/docs/context/rules
- [P] Field data (Feb 2026 snapshot, 2,853 GitHub repos using Claude Code,
  Copilot, Cursor, Gemini or Codex): of 2,586 repos with a context file,
  CLAUDE.md appears in 1,187 (45.9%), AGENTS.md in 1,021 (39.5%),
  `copilot-instructions.md` in 930 (36.0%). Skills in 158 repos, subagents
  in 131. "Context Files dominate the configuration landscape and are often
  the sole mechanism in a repository." Galster et al., arXiv 2602.14690
  (v5, Jun 30, 2026). Possibly stale: Feb 2026 data.

[O] Slide line: an AGENTS.md is the right place for non-obvious commands
and conventions; an overview of the repo the agent can read for itself
costs tokens and buys nothing measurable.

### 1.3 Agent Skills (SKILL.md)

- [P] Format: "a skill is a folder containing a `SKILL.md` file" with
  `name` and `description` at minimum, plus optional `scripts/`,
  `references/`, `assets/`. Loading is "progressive disclosure, in three
  stages": discovery (name and description only), activation (full
  SKILL.md), execution. https://agentskills.io/
- [P] History: Anthropic shipped skills for Claude on Oct 16, 2025 (claude.com
  blog, possibly stale; the donation post says only "October 2025") and
  published them as an open standard in December 2025; on
  **Oct 22, 2026** it donated "the Agent Skills name and logo, the GitHub
  organization, and the agentskills.io domain" to the AAIF. Lead maintainers
  David Soria Parra and Mahesh Murag; "Engineers from Anthropic, Google,
  OpenAI, and other companies will maintain the standard as individuals."
  Adoption: "So far, 1 million skills have been published and nearly 280
  million installed"; "More than 70 agent platforms" have integrated it,
  named examples "ChatGPT, Cursor, GitHub Copilot, and VS Code". Roadmap:
  "versioned releases, a formal proposal process, and security guidance for
  people who write and install skills". [P] (all wording confirmed in the
  verification pass)
  https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation
- [P] A vendor-neutral folder is emerging: **`.agents/skills/`**. Codex
  scans `.agents/skills` from the working directory up to the repo root and
  `$HOME/.agents/skills`, and links to the "open agent skills standard"
  (https://learn.chatgpt.com/docs/build-skills.md). Cursor loads
  `.agents/skills/` and `.cursor/skills/`, and "For compatibility, Cursor
  also loads skills from Claude and Codex directories" (`.claude/skills/`,
  `.codex/skills/`) (https://cursor.com/docs/context/skills). Claude Code
  does not read `.agents/` (`round5-claude-code.md`). Copilot reads
  `.claude/skills/` (`track1-agent-skills.md`).
- [R] "Agent Skills is Anthropic's proprietary format." Stale since Oct 22,
  2026; the standard and its domain belong to the AAIF.

### 1.4 Agent Client Protocol (ACP)

- [P] Purpose: ACP "standardizes communication between _code editors_ ...
  and _coding agents_". Local agents run as editor subprocesses using
  "JSON-RPC over stdio"; remote agents over HTTP or WebSocket, and "Full
  support for remote agents is a work in progress." It "re-uses the JSON
  representations used in MCP where possible." https://agentclientprotocol.com/
- [P] Origin: Zed launched it on Aug 27, 2025 (Nathan Sobo), with Gemini CLI
  as "the initial reference implementation". The stated analogy: "Just as
  the Language Server Protocol unbundled language intelligence from
  monolithic IDEs". https://zed.dev/blog/bring-your-own-agent-to-zed
  (possibly stale, 2025). [S] JetBrains announced co-development on Oct 6,
  2025; the ACP Registry launched Jan 28, 2026.
- [P] Repo `agentclientprotocol/agent-client-protocol`: created Jun 23,
  2025, Apache 2.0, about 4,600 stars (4,578 via the GitHub API on
  2026-11-04; latest release v1.15.1, Nov 2, 2026). "The current stable ACP protocol
  version is `1`." A v2 schema is in alpha (schema-v2.0.0-alpha.13, Nov 2,
  2026). Official SDKs in Kotlin, Java, Python, Rust, TypeScript.
- [P] ACP is **not** an AAIF project (absent from aaif.io/projects on
  2026-11-04).
- [P] Registry (`agentclientprotocol/registry`, 2026-11-04): 45 agent
  entries, including Claude Agent, Codex, Cursor, GitHub Copilot (CLI and
  extension), Google Antigravity, Gemini, Junie, Kiro, Goose, OpenCode (v1
  and v2), Cline, Devin, Factory Droid, Amp, Augment (`auggie`), Mistral
  Vibe, Qwen Code, Kimi, Grok Build, Poolside, Pi (via adapter).
- [P] How the big vendors connect (registry `agent.json` files):

| Agent | How it speaks ACP | Authors listed | Licence |
|---|---|---|---|
| Claude | `@agentclientprotocol/claude-agent-acp` wrapper on the Claude Agent SDK ("via Zed's SDK adapter" on the ACP site) | Anthropic, Zed Industries, JetBrains | proprietary |
| Codex | `@agentclientprotocol/codex-acp` adapter | OpenAI, JetBrains, Zed Industries | Apache-2.0 |
| GitHub Copilot CLI | native `copilot --acp` (public preview from Jan 28, 2026 per the ACP agents page link) | GitHub | proprietary |
| Cursor | native `cursor-agent acp` binary, version 2026.10.22 | Cursor | proprietary |
| Google Antigravity | native ACP server binary `agy_acp_server` | Google LLC | proprietary |

- [O] So Claude Code and Codex reach ACP editors through adapters around
  their SDKs; Copilot, Cursor, Gemini CLI, Antigravity, Kiro, Junie and
  goose ship ACP in the product. `round5-claude-code.md` records no native
  ACP in Claude Code's docs or changelog.
- [P] Clients listed on https://agentclientprotocol.com/overview/clients:
  Zed, JetBrains, Neovim (four plugins), Emacs, VS Code (community
  extensions), Visual Studio (Poolside), Qt Creator, Sublime Text, Obsidian,
  GitKraken Kepler, Devin Desktop, Microsoft's Intelligent Terminal (a
  Windows Terminal fork), and dozens of desktop and web orchestrators.
- [P] Barbaste et al. (arXiv 2609.00006, Jul 2026) found ACP shipped in 6 of
  11 open or source-available harnesses (Mistral Vibe, OpenClaw, OpenCode,
  Hermes, OpenHands, Gemini CLI) and describe "a new third role of harness
  hosting": ACP now serves editors, agent hosting, and (via A2A) the
  cross-vendor mesh.

### 1.5 Hooks: a shared vocabulary without a standard

- [P] No standards body owns hooks. What exists is copying of Claude
  Code's event names, JSON-over-stdin payloads and exit code 2 = block.
- [P] Evidence of the copying:
  - Codex: 14 events (`SessionStart`, `SessionEnd`, `SubagentStart`,
    `SubagentStop`, `PreToolUse`, `PermissionRequest`, `PostToolUse`,
    `PreModelRequest`, `PostModelRequest`, `PreCompact`, `PostCompact`,
    `UserPromptSubmit`, `Stop`, `Interrupt`); handlers `command` and
    `mcp_tool`, with `prompt` and `agent` "parsed but skipped"; plugin hooks
    get `CLAUDE_PLUGIN_ROOT` and `CLAUDE_PLUGIN_DATA` "for compatibility with
    existing plugin hooks". https://learn.chatgpt.com/docs/hooks
  - Cursor: 18 agent events in camelCase (`preToolUse`,
    `beforeShellExecution`, `afterFileEdit`, `stop` and others), plus 2 Tab
    events and `workspaceOpen`. Cursor "supports loading hooks from
    third-party tools like Claude Code"; exit code 2 "matches Claude Code
    behavior for compatibility"; `CLAUDE_PROJECT_DIR` is an alias "(Claude
    compatibility)". https://cursor.com/docs/agent/hooks
  - Crush v0.99.0 (Oct 29, 2026): "Most hook scripts written for Claude Code
    run under Crush unchanged" (`round5-oss-terminal.md`).
  - Copilot CLI and VS Code read `.claude/settings.json` hooks
    (`track1-hooks.md`, `round3-hooks-context-memory.md`).
  - Barbaste et al. (abstract): "Codex adopts Claude Code's hook vocabulary
    verbatim and ships an importer for its sessions and settings" [P].
- Event counts as of Nov 2026: Claude Code 33 (`round5-claude-code.md`),
  Cursor 21, Codex 14, Crush 13, Gemini CLI 11 (per 2609.00006, Jul 2026),
  VS Code Local harness 8 (`round2-copilot-changes.md`).
- [R] "There is a hooks standard." There is none; payload fields and
  handler types differ (Codex skips `prompt` and `agent` handlers; Cursor
  uses camelCase names and a `loop_limit` default of 5).
- [O] For a bank: write hooks against the Claude Code shape (`PreToolUse`,
  stdin JSON, exit 2) and they will run in the most places, Copilot
  included. Test on each tool; some fail open on timeout (round 2).

### 2.3 Why each vendor says it chose its format

- [P] OpenAI, GPT-5.1 guide (archived cookbook, late 2025, possibly stale):
  "With GPT-5.1, you can use apply_patch as a new tool type without writing
  custom descriptions for the tool." "Under the hood, this implementation
  uses a freeform function call rather than a JSON format." "In testing, the
  named function decreased apply_patch failure rates by 35%."
  https://developers.openai.com/cookbook/examples/gpt-5/gpt-5-1_prompting_guide
- [P] Anthropic: the Claude Code team says the dedicated Edit tool exists
  mainly so the UI can render diffs, and "we could probably just remove file
  edit and be totally fine" (Cat Wu, Jul 2026, via Willison's transcript;
  see `round5-claude-code.md` §3).
- [P] Thorsten Ball's 2025 teaching agent used the same shape: edit_file
  "Replaces 'old_str' with 'new_str' in the given file."
  https://ampcode.com/notes/how-to-build-an-agent (Apr 15, 2025, possibly
  stale)
- [P] Cursor, May 14, 2024 (Aman Sanger, stale): fast apply rewrote whole
  files with a 70B model at about 1,000 tokens/s using "speculative edits",
  because "Diffs force the model to think in fewer tokens", models have seen
  more full files than diffs, and models count line numbers badly. In their
  tests of search/replace, only Claude Opus produced accurate diffs
  reliably. https://cursor.com/blog/instant-apply
- [S] Morph sells fast-apply models (claims about 10,500 tokens/s and
  "~35% faster end-to-end task completion compared to search-and-replace");
  vendor numbers, no independent check.
- [O] Fast apply was a 2024 answer to models that could not write reliable
  diffs. None of the open harnesses we read in Nov 2026 uses a separate
  apply model; they rely on the frontier model to emit str_replace or
  apply_patch directly.

## 3. Code search and context retrieval

### 3.1 The three approaches

| Approach | Who | How |
|---|---|---|
| Agentic grep | Claude Code, Codex, Gemini CLI, OpenCode, Pi, Cline, Cursor (since Jul 2026), Copilot CLI (as default tool) | model calls ripgrep/glob/read in a loop; no pre-built index of meaning |
| Indexed grep | Cursor Instant Grep | local sparse n-gram index anchored to a git commit, edits layered on top [P] |
| Embedding index | GitHub Copilot (VS Code, cloud agent, CLI online sessions), Augment Context Engine, Junie (IDE semantic index) | vector search over chunks, server or local |
| Repo map | Aider (only one in the 2609.00006 corpus) | tree-sitter symbols ranked by PageRank-style graph, fitted to a token budget (`round5-oss-terminal.md`) |
| LSP / IDE symbols | Crush, Claude Code (code intelligence plugins), Copilot CLI (C++ preview), Junie | go-to-definition, references, rename |

### 3.2 What each side argues, with dates

**Against embeddings**

- [P] Claude Code (Boris Cherny, Latent Space, May 7, 2025, possibly
  stale): early versions used RAG; agentic search won on internal
  benchmarks "but mostly vibes", and an index "drifts out of sync" and has
  "security issues". Full quote in `round5-claude-code.md` §3.
- [P] Barbaste et al. (Jul 2026), source study of 11 harnesses:
  "Every coding environment already ships a near-optimal retrieval system in
  the form of ripgrep, find, and glob." "Code changes minute to minute, so
  pre-indexed embeddings are stale almost by construction." "No system uses
  vector-embedding RAG for code retrieval." Observation 9: agentic
  frameworks and vector code RAG "are missing from all eleven systems."
  [P] (first two quotes in §13.2, last two in Observation 9 of the HTML
  full text; the abstract's own wording is "none retrieves code with
  vector embeddings")

**For embeddings, then reversed: Cursor**

- [P] Nov 6, 2025 (Stefan Heule, Emily Jia, Naman Jain): Cursor trained its
  own embedding model and reported "12.5% higher accuracy" on its internal
  Context Benchmark (6.5% to 23.5% depending on model), "0.3%" more code
  retention (2.6% on large codebases), and said "the combination of these
  two leads to the best outcomes". https://cursor.com/blog/semsearch
  (possibly stale)
- [P] Mar 23, 2026 (Vicent Marti), "Fast regex search: indexing text for
  agent tools": "the agents just _love_ to use `grep`"; `rg` calls over 15
  seconds on large repos; Cursor built a local sparse n-gram index. The
  post contrasts the two indexes: a semantic index tolerates staleness,
  while regex search "must be very fresh". https://cursor.com/blog/fast-regex-search
- [P] July 2026, Cursor staff on the forum: "we recently made some changes
  to how agents search the codebase"; the older semantic path "was rapidly
  no longer helping in a meaningful way" because models "have gotten really
  good at using grep / indexed search" (Maxime, Jul 21). "Semantic/embeddings
  indexing is being turned down in favor of grep-based retrieval" (Colin,
  Jul 22). "no embeddings involved anywhere in it" (forum user mohitjain,
  Jul 31). Users first saw semantic search disappear on Jul 2, 2026. [P]
  for the quoted wording and dates (re-fetched in the verification pass;
  thread opened Jul 16, 2026). Still [P\*] for staff status: no staff
  badge is visible in the page text, the posters speak for Cursor ("our
  Instant Grep tool"). The Jul 2 date was not re-checked.
- [P] Current docs: Instant Grep is "a custom search engine that
  outperforms `ripgrep` on large codebases" that "builds and queries its
  index on your machine", and Cursor "does not store embeddings of your
  codebase for search". https://cursor.com/docs/agent/tools/search
- [R] "Cursor relies on a semantic embeddings index" and "Cursor's semantic
  search adds 23.5% over grep" are both out of date or misframed. The 23.5%
  was the top of a per-model range in the Nov 2025 post, and the feature was
  turned off in July 2026.

**For embeddings, and expanding: GitHub Copilot**

- [P] Sep 24, 2025 (Shengyu Fu, Microsoft CoreAI): new Copilot embedding
  model, "37.6% lift in retrieval quality", about 2x throughput, about 8x
  smaller index (possibly stale).
  https://github.blog/news-insights/product-news/copilot-new-embedding-model-vs-code/
- [P] Mar 17, 2026: the cloud agent got a semantic code search tool; tasks
  finished in "2% less time without any change in quality".
  https://github.blog/changelog/2026-03-17-copilot-coding-agent-works-faster-with-semantic-code-search/
- [P] Oct 19, 2026: Copilot CLI v1.0.100 "Enable semantic code search by
  default for online sessions" (`round5-copilot-architecture.md` §3.1).
- [P] Oct 28, 2026, "GitHub intelligence": semantic search finds code "by
  what it does", plus exact-text, symbol and regex search across an org's
  repositories without a local clone.
  https://github.blog/changelog/2026-10-28-github-intelligence-puts-your-code-context-and-history-to-work/
- [O] GitHub's position differs because it holds the code server-side:
  its index lives next to the repo, so the staleness and security arguments
  against a client-built index carry less weight. GitHub's own measured gain
  for the agent (2% faster, same quality) is small.

**Augment** [S]: markets its Context Engine as semantic retrieval and claims
a "12% hallucination rate compared to 28-31%" for long-context approaches.
Self-reported; not checked against a primary benchmark page.

### 3.3 Independent evidence

| Study | Date | Finding |
|---|---|---|
| Sen, Kasturi, Lumer, Gulati, Subbiah, "Is Grep All You Need? How Agent Harnesses Reshape Agentic Search", arXiv 2605.15184 | May 14, 2026 | On a 116-question LongMemEval sample (conversation memory, not code), grep "generally yields higher accuracy than vector retrieval"; scores "depend strongly on which harness and tool-calling style is used" across a custom harness, Claude Code, Codex and Gemini CLI [P\*] |

### 4.3 The 2026 trend toward shorter prompts, stated precisely

- [P] Prose is shrinking for frontier models: Claude Code's 80% cut (Jul 24,
  2026, `track2-thin-harness-evidence.md`), Copilot's ~70-line Opus 5
  prompt (Jul 24, 2026), OpenCode removing its "legacy Anthropic prompt"
  (Sep 5, 2026), Cline's 603-word act prompt.
- [P] Barbaste et al., Observation 3: "Prompt rhetoric converges where
  engineering experience converges, then _thins_ as trust calibrates."
  [P\*] And: "behavioral policy migrates from prompt prose to
  configuration" (the abstract carries this idea; exact wording not
  re-checked).
- [P] Counter-examples: Codex's GPT-6.x prompts (2,790 to 3,366 words) are
  2.6 to 3.1 times its GPT-5-Codex prompt (1,088 words) (~~"about 3,300

- [P\*] Total requests grew anyway, because tool definitions and capability

- [R] "Claude Code now sends 80% less to the model." The 80% refers to the
  system prompt text. Its first request in Aug 2026 was still about 74K
  characters, mostly tool schemas.
- [O] Slide line: the instructions got shorter; the tool manual got
  longer. Deferred tool loading (tool search) is how harnesses fight the
  second problem.

## 5. The common core: one loop

- [P] Thorsten Ball (Amp), Apr 15, 2025: "It's not that hard to build a
  fully functioning, code-editing agent." "It's an LLM, a loop, and enough
  tokens." An agent is "an LLM with access to tools, giving it the ability
  to modify something outside the context window." "The rest, the stuff
  that makes Amp so addictive and impressive? Elbow grease."
  https://ampcode.com/notes/how-to-build-an-agent (possibly stale)
- [P] Simon Willison, Sep 18, 2025: "An LLM agent runs tools in a loop to
  achieve a goal." "The “tools in a loop” definition has been popular for a
  while—Anthropic in particular have settled on that one."
  https://simonwillison.net/2025/Sep/18/agents/
- [P] Claude Code docs: three phases, "gather context, take action, and
  verify results"; "The agentic loop is powered by two components: models
  that reason and tools that act. Claude Code is the layer around the model
  that provides the tools and manages the context the model sees. This
  surrounding layer is what the term agentic harness refers to."
  https://code.claude.com/docs/en/how-claude-code-works
- [P] Liu, Zhao, Shang, Shen, "Dive into Claude Code", arXiv 2604.14228 (v3
  Oct 10, 2026): "The core of the system is a simple while-loop that calls
  the model, runs tools, and repeats." "Most of the code, however, lives in
  the systems around this loop": seven permission modes plus an ML
  classifier, a five-layer compaction pipeline, four extension mechanisms,
  subagent orchestration, append-oriented session storage. [P\*]
- [P\*] Barbaste et al., Observation 1: loop sophistication does not
  predict benchmark results; mini-swe-agent's minimal loop scores in the
  same range as OpenHands's event-sourced engine. Their Listing 1 condenses
  the loop to about 22 lines.

### 5.1 How a harness decides the turn is over

| Convention | Harnesses | Evidence |
|---|---|---|
| Model replies with no tool call | Claude Code, Ball's agent, most loops | `round5-claude-code.md` §2; Ball post |
| Same, stated in the prompt | Cline: "IMPORTANT: Always includes tool calls in your response until the task is completed. Response without tool calls will considered as completed with final answer." (typos in source) | [P] act.ts |
| Explicit completion tool | Gemini CLI `complete_task`; Cline `submit_and_exit`; Copilot SDK tools marked `isTerminal` | [P] sibling files; model-tool-routing.ts |
| Special final channel | Codex "persistent mode": "a `final` answer immediately ends the turn", so the model sends updates with `send_user_message_async` while work remains | [P] models.json `persistent_instructions` |

### 5.2 Layers every serious harness adds to the loop

[O] From the 2026 source studies and the sibling files, the parts that
recur everywhere: (1) a read/search/edit/execute tool set ("the same four
core capability categories (read, search, edit, execute) appear across all
LLM-driven agents", Rombaut [P\*]); (2) instruction files; (3) compaction
by LLM summary; (4) subagents with their own context ("Coordinator-worker
emerges independently across the corpus", Barbaste §11.10 [P]; the
"Obs. 7" label was not confirmed); (5) a
plan mode that removes write tools; (6) approval modes plus an optional OS
sandbox; (7) MCP, skills and hooks; (8) a headless or SDK mode. What
differs is defaults, safety depth and which model the harness is tuned for.

## 9. [O] Notes for the presentation

1. **One slide, one loop.** Ball's "an LLM, a loop, and enough tokens" next
   to Dive into Claude Code's "simple while-loop" and "Most of the code ...
   lives in the systems around this loop." The audience then sees the rest
   of the talk as "what goes around the loop".
2. **Standards slide.** Timeline: MCP (Nov 2024), AGENTS.md (Aug 2025), ACP
   (Aug 2025), AAIF (Dec 2025), A2A joins (Aug 2026), Skills joins (Oct
   2026). Copilot supports all of them, so the bank's Copilot-only rule does
   not lock its instruction files, skills or hooks to one vendor.
3. **Edit-format slide.** Two camps by model maker; the hashline result
   (6.7% to 68.3% for one model) shows the harness can matter more than the
   model for weaker models.
4. **Search slide.** Cursor's reversal is the clearest 2026 story: it
   measured a gain for embeddings in Nov 2025 and switched them off eight
   months later, saying models had become good enough at grep. GitHub went
   the other way because its index lives with the code.
5. **Prompt slide.** "Instructions shorter, tool manual longer": Claude
   Code's 9.5K-character system prompt inside a 74K-character request.
6. Do not quote adoption numbers (60k repos, 70 platforms, 1M skills) as
   independent facts; they are the stewards' own counts.
